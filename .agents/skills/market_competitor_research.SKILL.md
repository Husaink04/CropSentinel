# Market Competitor Research

Use this skill when the user asks how CropSentinel compares to the market or when roadmap planning depends on current competitor expectations.

## Goal

Turn dated competitor evidence into honest, actionable product implications for CropSentinel.

## Workflow

1. Research only current, attributable sources.
2. Anchor every claim with a date.
3. Compare each competitor claim against CropSentinel repo evidence before calling it a gap.
4. Separate findings into:
   - already implemented
   - partially supported foundations
   - clearly missing
5. Call out privacy, transparency, and evidence-retention tradeoffs in any suggested parity feature.
6. End with product implications:
   - must-have parity
   - differentiators worth keeping
   - features to avoid copying blindly

## Reporting Format

- Competitor and source date
- Claimed capability
- CropSentinel status
- Evidence path in repo
- Recommended response
